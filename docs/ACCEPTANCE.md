# 实机验收（尚未执行）

不要以 CI 通过替代下列检查。记录 OS/架构、应用 SHA256、打印机型号/固件、驱动、DPI、介质和扫码枪设置。

1. Win7 SP1 x64：安装/启动 legacy 包，中文 UI、字体、系统打印、TCP 打印、卸载；无网络环境运行。使用最新适用于该系统的补丁。EOL 风险无法由本应用消除。
2. Windows 10/11 x64、Ubuntu 22.04 amd64/arm64：分别安装和启动对应包；检查非管理员用户、Linux sandbox 与 CUPS 权限。CI 的 `--no-sandbox` 只适用于测试环境，不是安装包运行方式。
3. HID 扫码枪：匹配键盘布局，前导零、大小写、空格、Enter 后缀、连续扫描、重复扫描保护、切换窗口后重新聚焦。测试设备发出的 AIM 真实值，不假设所有厂家一致。
4. 每种码制扫描打印后的实物，核对解码内容逐字符一致。QR 含中文、emoji、URL 和打印指令样式字符；Code128 含空格/引号/^/~；EAN-13 含前导零。
5. 用尺确认 60×40 mm 和其他尺寸、模块宽度、静区与 DPI；确认系统驱动没有适应页面缩放。不同介质对比预览与实物。
6. 系统队列与 ZPL/TSPL 各测试 1/2/100 份，网络端口错误、打印机拒绝连接、断网、写到一半断电、缺纸、开盖、驱动离线。核对“已提交”仍可能无纸；不确定结果必须人工核对后重打。
7. TSPL 只用连续纸。ZPL 位图与 TSPL 黑白极性确认，避免整张反白/全黑、行字节 padding 异常。
8. 快速不同条码连续输入，确认顺序；提交中关闭进程、重启，确认没有自动重发；人工明确重打才出新任务。
9. 磁盘满、只读历史、损坏 JSON 的恢复与备份。历史含敏感内容时确认本机 ACL、磁盘加密和删除策略。
10. 标准用户安装未签名包，确认未知发布者提示与操作规程；核对下载 SHA256。应用无自动更新，升级前备份历史。

验收结果应以实测表记录，不应将本清单标为已完成。
